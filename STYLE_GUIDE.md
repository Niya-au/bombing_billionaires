# Team Style Guide

This document defines the shared visual style for the game.
All levels and UI should follow these guidelines to keep the game visually consistent.

## Shared Global Style

- Base tile size: **32x32 pixels**
- Taller props such as columns may use **32x64 pixels**
- Art style: **Pixel art**
- **No anti-aliasing**

Pure black (#000000) should not be used.

Instead, use:

- Warm dark shadow: `#2B1B16`
- Cold dark shadow: `#182235`
- Highlight: `#F6E7C8`

These colors are shared across all levels.
